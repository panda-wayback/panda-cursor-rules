# panda-cursor-rules

Personal Cursor plugin marketplace.

## Plugins

- `module-workflow` — Module + `interface.yaml` 开发流程与文档规则

## Install in Cursor

1. Open **Customize**
2. **From GitHub Repository**
3. Paste: `https://github.com/panda-wayback/panda-cursor-rules`
4. Install `module-workflow` (scope: user / myself)

## Local development

Working copy for quick edits:

```text
~/.cursor/plugins/local/module-workflow/
```

After changing rules, sync into this repo and push, then Refresh in Cursor.
